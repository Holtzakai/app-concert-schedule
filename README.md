# 演奏会進行表メーカー

演奏会の本番・GPスケジュールを自動計算し、A4横のPDFまたはExcelとして出力する静的Webアプリです。入力内容はブラウザー内だけで処理され、この端末に自動保存されます。

## 使い方

`index.html` を静的Webサーバーで公開してください。開発時は次のコマンドで起動できます。

```bash
npm run dev
```

ブラウザーで `http://localhost:4173` を開きます。

- 「演奏」「休憩」「進行」を追加し、上から順に入力します。
- 演奏開始、袖、チューニング、終了は自動計算されます。
- 「GPだけの演奏順を設定」で、本番とは異なるGP曲順へ並べ替えられます。
- 「本番」「GP」で出力プレビューを切り替えます。
- 「A4 横」「A4 縦」で、用途に合わせた出力レイアウトを選べます。縦版では時刻と照明をまとめて読みやすく表示します。
- 「PDFを出力」は、現在表示している本番またはGP進行表をA4横のPDFとして保存します。
- 「Excelを出力」は、本番・GP・入力データを含む `.xlsx` を保存します。
- 「中間データを保存」で編集中の内容をJSONとしてバックアップできます。
- 「JSONを読み込む」で保存済みの編集内容を復元できます。

## 検証とビルド

```bash
npm test
npm run build
```

ビルド結果は `dist/` に作成されます。詳しい設計は [docs/architecture.md](./docs/architecture.md) を参照してください。

## GitHub Pages

`.github/workflows/pages.yml` が `main` ブランチへの更新を検知し、静的サイトをGitHub Pagesへ公開します。リポジトリの Settings → Pages で Source を「GitHub Actions」に設定してください。
